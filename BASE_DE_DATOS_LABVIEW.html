Base de datos / LabVIEW

    INTRODUCCIÓN

    Este proyecto desarrolla un sistema de adquisición de datos con LabVIEW conectado a una base de datos SQL. Permite registrar, visualizar y analizar de forma histórica las variables de un proceso industrial o de laboratorio.

    La arquitectura combina la captura en tiempo real desde sensores y actuadores, el procesamiento de señales en el entorno gráfico de LabVIEW y el almacenamiento estructurado en base de datos para consultas y generación de informes.
